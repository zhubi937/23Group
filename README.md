## 提醒与真实系统权限

- 日程默认提前 **5 小时**，可改默认值，也可在每条日程中按分钟覆盖。已经过去的提醒时间不会补发。
- 相机按使用场景弹出系统授权。相册和文档通过系统选择器逐项授权，不申请整个相册或存储的访问权限。
- 通知开关会调用真实的系统通知授权，并读取系统结果。应用内“读取校园页面”只是数据使用同意，不冒充系统权限。
- 代理提醒未开通华为开放权益时，设备可能返回 `1700002`。应用尝试使用**本应用自己的系统日历账户**登记同一日程和提醒，需要真实的日历读写授权。
- 提醒保存原生 ID 与登记状态；变更、取消、完成、删除和退出账号时更新或取消本应用登记的提醒。登记失败会保留原因，不显示虚假的“已提醒”。
- 喝水提醒一次登记未来三天内最多 12 条，打开应用可手动续订；不声称可无限期在后台自行续订。
- 设置中有短时后台测试提醒。是否出现横幅、锁屏或声音，还受系统日历/通知设置、免打扰和设备实现影响。当前设备的实测结果见下方验收记录。

官方依据：[代理提醒的管控和 Calendar Kit 替代方式](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/agent-powered-reminder/)。若后续要使用独立代理提醒，需项目拥有者在 AppGallery Connect 申请、开启对应能力并重新生成自己的签名 Profile；源码不能替代此项平台授权。

## 模型训练与可复现性

两个语义模型是本次实际训练的 **512 → 64 → 32 → 6 多层神经网络**，含 ReLU 隐藏层、softmax 输出、反向传播和 Adam。分别判断六种日程类型、六种文字角色。不是把关键词判断改名为深度学习。

| 项目 | 数据与结果 |
|---|---|
| 分类模型 | 3,600 条训练通知 / 600 条测试通知；合成测试准确率 87.17%，macro-F1 0.8705 |
| 文字角色模型 | 18,600 条训练片段 / 3,100 条测试片段；合成测试准确率 70.52%，macro-F1 0.6785 |
| 验证分离 | 留出不同学科/组织/地点词汇及日期/时间表述；部分任务标题模板共享。没有使用你的个人通知 |
| 端侧一致性 | 24 条导出向量逐项对比 NumPy 与 ArkTS 概率，误差上限 0.00001 |

**以上只是合成样本结果，不能当作真实校园通知准确率。** 文字角色模型仍有明显误判空间，因此保留原文、置信度门槛、规则时间校验和人工修改；不自动把所有提取结果判定为可靠。它是小型分类/角色网络，不是通用大语言模型，也不是从零训练中文 OCR。

OCR 使用单独授权的 Tesseract 5.5.0 / Leptonica 1.85.0 和 `chi_sim+eng` 预训练 LSTM。图片识别走 C++ 异步任务，语义推理走 TaskPool，减少阻塞界面。

```powershell
# Python 3.12，安装 NumPy 后可以重新训练
python -m pip install numpy
python .\ml\train.py --epochs 25
.\scripts\test.ps1 -DevEcoHome 'C:\path\to\DevEco Studio'
```

训练脚本、固定种子、权重、混淆矩阵、各类 F1、校验值和概率对照在 `ml/`、`entry/src/main/resources/rawfile/ml/`。训练后如需提交新模型，应重新运行测试和原生验收，不应沿用旧报告。

## 文件读取限制

- 单文件最大 20 MB，图片最大 4,000 万像素，OCR 解码会缩放。
- DOCX 只提取 `word/document.xml`；验证 ZIP 目录、路径、正文头和 CRC；C++ 后台解压输出上限 4 MB，不把整个压缩包释放到磁盘。不支持密码加密 DOCX、旧 DOC 或图片化 Word 的隐含内容。
- PDF 完全本地解析，正文优先读取；扫描页转图后用离线 OCR。每次最多 40 页，纯扫描文件最多 10 页，扫描解码总量超过限制会要求拆分；加密或损坏文档会提示，不会默默生成空日程。
- ICS 当前支持明确日期的 VEVENT 和 UTC 时间转换；**未展开 RRULE 重复规则、EXDATE 和完整时区定义**，请在导出端展开课程日期。未实现部分不伪造数据。
- 一次最多整理 20 条通知，超出时提示分批处理；原文仍保留。识别不能保证覆盖任意页面排版或任意文档表格。

## 使用与演示

### 添加和核对

- 点击底部独立 `+`，选择导入截图或输入文字。系统图片选择器只选择一张图片，取消不建立事项。
- 选图后先保存本机副本并计算完整文件 SHA-256；相同字节的图片复用来源。拒绝空文件、超过 20 MB 或超过 4000 万像素的输入。
- 系统 OCR 可用时优先使用系统；不支持、初始化失败或结果为空时，自动使用 Tesseract 5.5.0 中英文离线引擎。实际识别异步运行，行/词坐标映射回原图。
- 抽屉默认半屏核对。点击快捷字段或输入框上方的“定位原文”，原图出现红框，抽屉收至低档；“继续核对”回到中档，“展开”进入高档，也可以拖动顶部区域。
- 逐项修改后保存。手工文字重新整理会明确标记无图像坐标，不会为修改后的文字伪造红框。
- 中文字段保留拼音预编辑保护。模拟器电脑键盘的中文输入仍受宿主输入法通道影响，可使用屏幕拼音选词或复制粘贴；不能把自动注入中文的测试当作电脑实体键盘输入法已修复。

### 延期与多来源

1. 来源页打开“作业通知”样例，确认并保存；截止为 `2026-12-18 23:59`。
2. 打开“延期通知”样例。关联建议显示原作业、匹配原因与截止差异；保持独立或关联都由你决定。
3. 若只想延期，只勾选截止字段，核对确认弹窗后保存。新截止为 `2026-12-20 23:59`，详情保留两份来源及原来的历史值。
4. 来源档案还可“仅补充来源到已有事项”；此路径只新增来源关系，不采用截图中的字段。
5. 解除来源后，已有历史仍引用这份原图。可归档保留，但不能通过永久删除损坏历史依据。

样例都是自制图片，预置文字和坐标明确标记，**不能当作真实 OCR 准确率证据**。真实截图没有预置结果；识别错字和不完整日期必须核对。W07 已验证真实课程提交截图的正文标题、17 段原文、截止 `2026-11-15 23:59` 与局部词级红框，仍保留这条真实识别路径。

### 外观与交互

- 底部点击或横滑切换事项、来源、外观；页面滚动位置与搜索条件保留。再次点击当前栏目回到顶部。
- 外观页选择颜色后即时应用，不跳回首页；设置顺序写入并落盘，快速多次选择以最后一次为准。
- “清晰模式”适合更重视文字清楚、对透明背景敏感的使用者；“减少动态效果”可同时开启。
- 胶囊位于应用安全区域内，仅表示本应用正在进行的操作，不覆盖系统状态栏，也不是系统级灵动岛。

数据库沿用 `screenshot_tasks.db`：`tasks`、`sources`、`history`、`source_history` 四表。SQL 参数绑定；图片存放在沙箱 `files/sources/`。来源保存原始识别和证据，事项保存人工确认值，历史保存前后快照。v1 迁移会补建旧历史的来源索引；失败保留旧数据，可重试。保存事项、历史与索引在同一事务中完成，并阻止陈旧版本覆盖新值。

系统提醒服务无法与 RDB 组成跨系统事务。提醒发布后如数据库保存失败，会尝试补偿取消；系统提醒取消失败等极端情况仍需真机复核。
