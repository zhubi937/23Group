# 截图成事 v0.7.2 更新日志

**发布日期**：2026-11-03  
**版本**：0.7.2

---

## 本次更新重点

**系统 OCR 不可用时，自动切换到本机离线识别**

之前版本只提示"不支持系统文字识别"，截图无法自动转写。现在系统 OCR 不可用时，会自动使用内置的 **Tesseract 5.5.0 + 中英文离线模型**，在手机本地完成识别，无需联网、无需 API Key。

---

## 实测验证

在 Mate 90 Pro 模拟器上，用真实课程作业截图测试：

- 成功识别 **17 段原文**，包括标题、截止时间、提交要求
- 点击"截止时间"，原图对应位置显示红框（基于真实词级 OCR 坐标）
- 修复了"截止"被误识别为"裁止"时的提示和候选时间逻辑
- 作业页面的开放区间不再误填为日程时间

---

## 主要功能一览

| 功能 | 说明 |
|---|---|
| 图片导入 | 系统选图、预览、保存副本；限制 20MB / 4000 万像素 |
| 截图查重 | SHA-256 哈希，相同图片自动复用 |
| OCR 识别 | 系统优先，失败自动切离线引擎 |
| 字段提取 | 标题、日期、时间、地点、截止、备注等 |
| 原文核对 | 点击字段定位原图红框 |
| 中文输入 | 支持拼音选词，键盘自动避让 |
| 手工补充 | 可手动输入原文，明确标注无坐标 |
| 事项管理 | 新建、编辑、完成、删除、搜索、筛选 |
| 基础关联 | 识别同一件事，支持字段级勾选更新 |
| 变更历史 | 记录前后值、来源、时间 |
| 系统提醒 | 支持日期提醒和 1 分钟测试提醒 |
