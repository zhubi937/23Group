# 截图成事 · W08 整合工程

基于多源信息整合的鸿蒙个人事务管理应用。本包是 **15 周计划中第 8 周的累计源码**，版本 `0.8.0`，包含 W07 的离线 OCR、原文红框、事项管理与历史，以及 W08 的关联排序、来源管理和玻璃交互改版。

技术使用 **ArkTS / ArkUI + C++ NAPI**，不是网页套壳。图片识别和数据保存均在本机完成，无需账号、API Key 或电脑识别服务器；应用不声明网络权限。

## 运行工程

1. 解压全部内容。在 DevEco Studio 中打开同时包含 `build-profile.json5`、`hvigorfile.ts`、`AppScope` 和 `entry` 的项目根目录。
2. 已用 DevEco Studio 26.0.0.821 / HarmonyOS 26.0.0 SDK 构建。工程的本机 OCR 源码、类型依赖、中英文模型均随包；首次原生编译需要几分钟。
3. 启动现有 Mate 90 Pro 模拟器，运行 `entry`。界面不绑定这个型号；其他手机、低版本系统和平板仍需实际验收。
4. 正式应用标识为 `com.jietuchengshi.app`。若需要签名，请在自己的 DevEco 环境配置；本包不携带个人证书、账号或设备签名。
5. 源码中没有你的事项、截图副本和本机数据库。首次安装为空；升级安装沿用应用沙箱，不要卸载旧应用后再安装来测试数据迁移。

Windows PowerShell 构建与测试：

```powershell
.\scripts\build.ps1 -DevEcoHome 'C:\path\to\DevEco Studio'
.\scripts\test.ps1 -DevEcoHome 'C:\path\to\DevEco Studio'
```

将示例安装路径替换成你自己的 DevEco Studio 目录。脚本只设置当前进程的 SDK/Java/Node 环境，生成本机 `local.properties`，通过自带 CMake/Ninja 构建 `x86_64` 和 `arm64-v8a` 的 C++ 离线引擎。HAP 构建输出为：

```text
entry/build/default/outputs/default/entry-default-unsigned.hap
```

包内只保留源码、运行资源、许可证、脚本、测试和本 README，不保留 `oh_modules`、`.hvigor`、`.cxx`、`build`、IDE 缓存、个人签名及设备数据。最低兼容配置为 API 12，目标/编译 SDK 为 26.0.0；最低配置不代表已验证所有旧设备。

## 使用与演示

### 添加和核对

- 点击底部独立 `+`，选择导入截图或输入文字。系统图片选择器只选择一张图片，取消不建立事项。
- 选图后先保存本机副本并计算完整文件 SHA-256；相同字节的图片复用来源。拒绝空文件、超过 20 MB 或超过 4000 万像素的输入。
- 系统 OCR 可用时优先使用系统；不支持、初始化失败或结果为空时，自动使用 Tesseract 5.5.0 中英文离线引擎。实际识别异步运行，行/词坐标映射回原图。
- 抽屉默认半屏核对。点击快捷字段或输入框上方的“定位原文”，原图出现红框，抽屉收至低档；“继续核对”回到中档，“展开”进入高档，也可以拖动顶部区域。
- 逐项修改后保存。手工文字重新整理会明确标记无图像坐标，不会为修改后的文字伪造红框。
- 中文字段保留拼音预编辑保护。模拟器电脑键盘的中文输入仍受宿主输入法通道影响，可使用屏幕拼音选词或复制粘贴；不能把自动注入中文的测试当作电脑实体键盘输入法已修复。

### 延期与多来源

1. 来源页打开“作业通知”样例，确认并保存；截止为 `2026-12-18 23:59`。
2. 打开“延期通知”样例。关联建议显示原作业、匹配原因与截止差异；保持独立或关联都由你决定。
3. 若只想延期，只勾选截止字段，核对确认弹窗后保存。新截止为 `2026-12-20 23:59`，详情保留两份来源及原来的历史值。
4. 来源档案还可“仅补充来源到已有事项”；此路径只新增来源关系，不采用截图中的字段。
5. 解除来源后，已有历史仍引用这份原图。可归档保留，但不能通过永久删除损坏历史依据。

样例都是自制图片，预置文字和坐标明确标记，**不能当作真实 OCR 准确率证据**。真实截图没有预置结果；识别错字和不完整日期必须核对。W07 已验证真实课程提交截图的正文标题、17 段原文、截止 `2026-11-15 23:59` 与局部词级红框，仍保留这条真实识别路径。

### 外观与交互

- 底部点击或横滑切换事项、来源、外观；页面滚动位置与搜索条件保留。再次点击当前栏目回到顶部。
- 外观页选择颜色后即时应用，不跳回首页；设置顺序写入并落盘，快速多次选择以最后一次为准。
- “清晰模式”适合更重视文字清楚、对透明背景敏感的使用者；“减少动态效果”可同时开启。
- 胶囊位于应用安全区域内，仅表示本应用正在进行的操作，不覆盖系统状态栏，也不是系统级灵动岛。

数据库沿用 `screenshot_tasks.db`：`tasks`、`sources`、`history`、`source_history` 四表。SQL 参数绑定；图片存放在沙箱 `files/sources/`。来源保存原始识别和证据，事项保存人工确认值，历史保存前后快照。v1 迁移会补建旧历史的来源索引；失败保留旧数据，可重试。保存事项、历史与索引在同一事务中完成，并阻止陈旧版本覆盖新值。

系统提醒服务无法与 RDB 组成跨系统事务。提醒发布后如数据库保存失败，会尝试补偿取消；系统提醒取消失败等极端情况仍需真机复核。
